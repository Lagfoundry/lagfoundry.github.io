Adaptive Biological AI Learner

A Portfolio Research Paper on Rich Experience, 3D Neural Tissue, Reflection, and Adaptive Glia

Project documentation for Brad Nelson

May 2026

Project Overview

This paper documents a code-based experimental architecture for a developmental, biological-style learner. The goal is to explain the engineering problem, the experimental progression, what worked, what failed, and why the next research step is adaptive glia patches inside a two-hemisphere 3D tissue model.

Executive Summary

The project moved away from flat binary input and toward rich experience objects that carry raw values, task context, relational information, operation-style views, memory traces, attention state, and teacher/reflection signals.

The best-performing version, v15, solved all three toy tasks by combining task-specific output heads, a reflection pass, normal-path replay, and an operation-style number-line workspace for addition.

The later 3D versions showed that spatial neural tissue can coexist with learning, but static global growth and pruning rules are too brittle. Pruning can be too fast, growth can be too loose, and survival alone does not guarantee useful pathways.

The current conclusion is that the base neuron and rich-experience learner are worth preserving. The next bottleneck is glia stability: glia-like regulators should become adaptive local agents that learn how to grow, prune, repair, stabilize, and protect pathways without producing task answers directly.

The next proposed direction is v21: two hemispheres, separate brain-like input regions, guided developmental corridors, and a small number of adaptive glia patches that learn local tissue regulation.

1. Motivation

Most neural-network experiments start from a fixed graph of layers and weights. This project started from a different question: what would a code-based learner look like if it were designed as a developmental tissue rather than a static feedforward network?

The goal is not to recreate all of biology. The goal is to explore engineering ideas inspired by biological learning: rich sensory context, reflection, memory, local tissue development, growth, pruning, repair, and support cells that regulate how the network changes over time.

The project is intentionally not hardware-constrained. Earlier binary-neuron and hardware-friendly ideas were useful stepping stones, but the current design direction is a software model of biological-equivalent learning. This allows richer internal state, analog error signals, dendrite-like branches, 3D tissue positions, slow structural turnover, and eventually adaptive glia patches.

2. Core Architecture

2.1 Rich experience objects

The first major shift was replacing flat input vectors with BioExperience objects. A sample is not only a few bits. It includes multiple typed signal channels that represent different ways the learner can experience the same task. 

BioExperience
    raw signals: direct values and simple measurements
    context signals: task identity and goal framing
    relation signals: greater-than, equality, distance, parity
    operation signals: count-up, number-line endpoint, step pressure
    memory signals: similar past cases and their errors
    attention signals: novelty, confidence, interest, frustration
    teacher signals: expected value, error direction, correction hints

This change made the learner less like a vector mapper and more like a small learning organism. It also made it possible to test the idea that different kinds of information should enter different tissue regions later.

2.2 Feedforward, reflection, and normal-path replay

The successful learning loop is not classic backpropagation. The learner first predicts normally, then reflects using teacher/error context, then replays the same input without teacher help before the final learning update. This normal-path replay was important because reflection can otherwise teach the network to depend on correction signals instead of improving the first-pass pathway. 

1. Feedforward pass:
       experience -> tissue -> task head -> predicted_norm

2. Reflection pass:
       experience + teacher/error context -> tissue -> reflected prediction

3. Normal-path replay:
       experience without teacher context -> tissue -> normal prediction

4. Learning update:
       analog error = expected_norm - normal_prediction
       update task head, assemblies, branches, synapses, memory, curiosity, and tissue regulation
