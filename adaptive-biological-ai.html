Adaptive Biological AI Learner

A Portfolio Research Paper on Rich Experience, 3D Neural Tissue, Reflection, and Adaptive Glia

Project documentation for Brad Nelson

May 2026

Project Overview

This paper documents a code-based experimental architecture for a developmental, biological-style learner. The goal is to explain the engineering problem, the experimental progression, what worked, what failed, and why the next research step is adaptive glia patches inside a two-hemisphere 3D tissue model.

Executive Summary

The project moved away from flat binary input and toward rich experience objects that carry raw values, task context, relational information, operation-style views, memory traces, attention state, and teacher/reflection signals.

The best-performing version, v15, solved all three toy tasks by combining task-specific output heads, a reflection pass, normal-path replay, and an operation-style number-line workspace for addition.

The later 3D versions showed that spatial neural tissue can coexist with learning, but static global growth and pruning rules are too brittle. Pruning can be too fast, growth can be too loose, and survival alone does not guarantee useful pathways.

The current conclusion is that the base neuron and rich-experience learner are worth preserving. The next bottleneck is glia stability: glia-like regulators should become adaptive local agents that learn how to grow, prune, repair, stabilize, and protect pathways without producing task answers directly.

The next proposed direction is v21: two hemispheres, separate brain-like input regions, guided developmental corridors, and a small number of adaptive glia patches that learn local tissue regulation.

1. Motivation

Most neural-network experiments start from a fixed graph of layers and weights. This project started from a different question: what would a code-based learner look like if it were designed as a developmental tissue rather than a static feedforward network?

The goal is not to recreate all of biology. The goal is to explore engineering ideas inspired by biological learning: rich sensory context, reflection, memory, local tissue development, growth, pruning, repair, and support cells that regulate how the network changes over time.

The project is intentionally not hardware-constrained. Earlier binary-neuron and hardware-friendly ideas were useful stepping stones, but the current design direction is a software model of biological-equivalent learning. This allows richer internal state, analog error signals, dendrite-like branches, 3D tissue positions, slow structural turnover, and eventually adaptive glia patches.

2. Core Architecture

2.1 Rich experience objects

The first major shift was replacing flat input vectors with BioExperience objects. A sample is not only a few bits. It includes multiple typed signal channels that represent different ways the learner can experience the same task. 

BioExperience
    raw signals: direct values and simple measurements
    context signals: task identity and goal framing
    relation signals: greater-than, equality, distance, parity
    operation signals: count-up, number-line endpoint, step pressure
    memory signals: similar past cases and their errors
    attention signals: novelty, confidence, interest, frustration
    teacher signals: expected value, error direction, correction hints

This change made the learner less like a vector mapper and more like a small learning organism. It also made it possible to test the idea that different kinds of information should enter different tissue regions later.

2.2 Feedforward, reflection, and normal-path replay

The successful learning loop is not classic backpropagation. The learner first predicts normally, then reflects using teacher/error context, then replays the same input without teacher help before the final learning update. This normal-path replay was important because reflection can otherwise teach the network to depend on correction signals instead of improving the first-pass pathway. 

1. Feedforward pass:
       experience -> tissue -> task head -> predicted_norm

2. Reflection pass:
       experience + teacher/error context -> tissue -> reflected prediction

3. Normal-path replay:
       experience without teacher context -> tissue -> normal prediction

4. Learning update:
       analog error = expected_norm - normal_prediction
       update task head, assemblies, branches, synapses, memory, curiosity, and tissue regulation

2.3 Dendrite-like branches and synapse state

Each neuron has branches that listen to different types of signal. A raw value and a teacher correction should not be treated as the same kind of input. Branches allow the same neuron to respond differently to raw sensory input, context, relation signals, operation signals, memory, teacher feedback, and attention state.

Synapses carry more than a weight. They track eligibility, usefulness, stability, fatigue, context usefulness, and later spatial-history properties.

2.4 3D tissue instead of flat layers

The project then moved from flat assemblies to a 3D tissue model. Neurons receive coordinates, local neighbors are cheaper to connect, long-range bridges are rarer and more expensive, and regions occupy different areas of simulated space.

This is not only a visualization. It changes the growth rule: connection probability and cost depend on distance and region relationship. 

Flat layer idea:
    input -> hidden -> output

3D tissue idea:
    cells have positions
    local neighborhoods form first
    rare bridges connect distant regions
    useful pathways stabilize over time
    glia learns how tissue should reshape

3. Experimental Version History

One shared scalar output and imbalanced binary tasks caused fake relation learning. The scaffold could run, but readout and teaching balance mattered.
v14C Task-specific heads and balanced binary teaching Equality and greater-than reached real 1.000 accuracy. Addition remained weak. Relation tasks needed task heads and balanced teaching; arithmetic needed a different representation.
v15 Normal-path replay plus operation-style arithmetic workspace Reached 1.000 accuracy on add, equality, and greater-than. v16 3D tissue with coordinates, local links, bridges, distance cost Reached 1.000 on all tasks and proved 3D tissue did not break learning. Spatial links were pruned very aggressively; only 8 survived by step 12000. 3D tissue can coexist with learning, but pruning timing was too harsh.

4. Key Results and Interpretation

4.1 v15: the strongest learning result

v15 was the first version that clearly solved the toy world. Its source notes describe four critical fixes: normal-path training after reflection, an operation-style arithmetic view, a clipped linear output for addition, and teacher feedback with operation-specific correction signals.

The final run reached add_accuracy=1.000, equality_accuracy=1.000, and greater_than_accuracy=1.000.

The engineering lesson is that addition did not behave like a simple relation-classification task. It needed an internal operation view, such as a number line or count-up workspace. That result supports a broader principle: a biological-style learner may need internal tools, not just input features.

4.2 v16-v20: 3D tissue worked, but fixed glia rules did not

v16 proved that a 3D tissue model did not automatically destabilize the learner. However, it pruned spatial links down to only 8 by step 12000. v17 corrected this by protecting spatial links longer, but spatial links overgrew to 1603 and addition stayed weak.

v18 controlled bridges but still failed addition. v19 made structural change probabilistic but pruned too aggressively. v20 slowed forgetting and preserved 862 spatial links, but addition still failed because the surviving paths were not the right arithmetic corridors.

These results suggest that the problem is not simply whether the system has enough tissue. The problem is whether tissue is guided into useful routes. A 3D learner needs local growth, slow forgetting, and corridor formation. Survival alone is not intelligence; stable useful pathways are the goal.

5. What Worked

5.1 Rich experience beat flat input

Moving away from flat binary input was one of the most important improvements. The learner became more expressive when each example included raw, context, relation, operation, memory, attention, and teacher channels.

5.2 Task-specific heads reduced interference

A shared scalar output allowed relation tasks to fall into majority-class shortcuts. Task-specific heads allowed addition, equality, and greater-than to build separate readouts.

5.3 Reflection needed normal-path replay

Reflection can improve an answer but accidentally train the corrected route. Normal-path replay forces the first-pass pathway to learn after reflection.

5.4 Operation-style workspace made addition learnable

Addition recovered only when the system received a number-line or count-up style operation view. This points toward future internal action systems.

5.5 3D tissue was viable

Adding coordinates, local links, rare bridges, and distance costs did not by itself break learning. This supports 3D tissue as the base architecture.

5.6 Slow forgetting was more realistic than instant pruning

v20 showed that history-protected forgetting preserved tissue much better than aggressive pruning. This matches the idea that connections should weaken first, then be deleted only after repeated evidence of nonuse or harm.

6. What Did Not Work

6.1 One shared output was too crude

The first rich biological rewrite had enough moving parts to run, but the single shared scalar output created shortcuts and task interference.

6.2 Growth-only infancy caused overgrowth

Protecting spatial links too long created a dense tissue that stayed alive but did not form the right arithmetic route. Biological development needs formation and elimination at the same time.

6.3 Probabilistic pruning was too fast at first

v19 used probabilistic pruning, which was the right type of mechanism, but it applied too often and too strongly. A chance-based guillotine is still a guillotine.

6.4 Stability alone did not create useful corridors

v20 preserved tissue, but many surviving links were same-region clusters rather than arithmetic routes such as raw_sense to operation or operation to integrator.

6.5 Fixed global glia rules are too brittle

The same pruning or growth schedule cannot serve every region. Relation tasks may need stability while addition needs plasticity and repair. This points directly toward adaptive glia patches.

7. Why Adaptive Glia Became the Next Bottleneck

The experimental sequence points to one central conclusion: the neuron/tissue side can learn, but fixed support rules cannot reliably manage tissue development. The system needs glia-like regulators that learn the network itself.

These regulators should not produce task answers. Instead, they should monitor local tissue health, remember what structural changes helped or hurt, and adjust growth, pruning, repair, stability, excitability, bridge permission, and plasticity. 

Neurons learn content:
    What does this signal mean?
    What should the answer be?
    Which operation helps this task?

Glia learn the tissue:
    Is this region overgrowing?
    Is this region underperforming?
    Did growth help?
    Did pruning hurt?
    Should plasticity reopen here?
    Should this pathway be stabilized?

This framing turns glia into meta-learning nodes. They are not part of the output answer, but they shape the system that produces future answers.

8. Related Research and Design Inspiration

This project should not claim that no one has used glia in AI. Related work already exists in artificial glial cells, astrocyte-modulated networks, structural plasticity, synaptic pruning, and neuromorphic growth. The distinctive direction here is the combination: rich experience objects, reflection, 3D tissue, slow forgetting, future hemispheres, and adaptive glia patches that learn local tissue regulation.

Research area What the literature suggests Design takeaway
Artificial glial cells in ANNs A 2023 systematic review reported that artificial astrocyte-style additions have been used in several ANN approaches and can improve tasks such as classification and regression. Use glia as modulators around neurons, not task-output units.
Astrocyte-gated plasticity Recent astrocyte-gated plasticity work uses slow astrocyte-like variables to modulate learning over time. Let glia gate plasticity: stable regions become less plastic, failing regions reopen learning.
Structural plasticity Neuromorphic structural-plasticity work shows dendritic growth can define useful sparse topologies based on activity. Prefer sparse useful topology over dense random wiring; use coactivity and distance.
Microglia and pruning Microglia research supports pruning as an activity-dependent regulatory process, not merely instant deletion. Use staged weakening, deletion marks, reuse protection, and slow forgetting.
Multisensory brain organization Biological sensory systems process different modalities through specialized pathways before later integration. Future versions should route different input types to dedicated regions before integration.

9. Proposed v21 Direction

The next step should not be a larger flat network. It should be a more organized biological structure. The highest-priority upgrade is to combine two hemispheres with adaptive glia patches and guided developmental corridors.

9.1 Separate hemispheres

More neurons should not simply be packed into the same 3D space. A separate hemisphere gives the system more capacity without crowding one tissue volume. One hemisphere can emphasize structured task and operation routes, while the other can emphasize memory, alternate views, reflection, and exploration. Cross-hemisphere bridges should be rare, expensive, and protected only if useful. 

Left hemisphere:
    structured task route
    raw -> relation -> operation -> integrator

Right hemisphere:
    associative route
    memory -> alternate views -> reflection -> integrator

Cross-hemisphere links:
    rare, expensive, protected if useful

9.2 Multi-entry sensory routing

A living organism does not experience the world through one input stream. It receives visual, auditory, touch/body, taste/smell, internal state, teacher/social, and memory signals through partly specialized systems. A software version should mirror this by routing different signal types into different 3D regions before integration. 

raw values or symbols        -> raw_pattern region
ordered/counting information -> sequence or operation region
comparisons and distance     -> relation region
confidence/fatigue/error     -> body_state region
similar past examples        -> memory region
teacher correction           -> teacher_error region
final synthesis              -> integrator region

9.3 Adaptive glia patches

Instead of one global GliaController, v21 should test a small number of local glia patches. A patch monitors a neighborhood and slowly adjusts its own regulatory biases. The first test should be deliberately small: perhaps one operation-region patch and one relation-region patch. This reduces code complexity while testing whether adaptive glia can stabilize one solved region and repair one struggling region. 

GliaPatch
    location: hemisphere, region, center, radius
    learned biases:
        growth_bias
        prune_bias
        repair_bias
        stability_bias
        bridge_bias
        plasticity_bias
        excitability_bias
    local memory:
        recent_error
        recent_improvement
        recent_regression
        growth_helped_score
        prune_hurt_score
        overgrowth_score
        underuse_score

9.4 Guided developmental corridors

Growth should not be fully random. Biology uses local neighborhoods, developmental gradients, and preferred projections. The code version can start with soft corridor biases, not hard-coded answers. For the current toy tasks, useful corridors likely include raw_sense to relation, relation to integrator, raw_sense to operation, relation to operation, operation to integrator, teacher to operation, and memory to operation.

10. Engineering Significance

The project demonstrates an iterative engineering process around an unconventional learning architecture. The important skill is not only that one version reached perfect scores on toy tasks. The important skill is identifying why it worked, why later versions failed, and what those failures imply about the architecture.

The sequence from v14 through v20 shows controlled experimentation: readout isolation, balanced training, reflection fixes, operation representation, spatial tissue, developmental schedule tuning, probabilistic pruning, and staged forgetting.

For a team evaluating this work, the value is in the design reasoning: the project turns biological hypotheses into runnable code, logs behavior, diagnoses failure modes, and converts results into a next architecture plan. It is an engineering exploration of adaptive systems rather than a claim of finished AGI.

11. Limitations

The tested task world is small: addition, equality, and greater-than over values 0 through 5.

Perfect task scores in v15 and v16 do not prove general intelligence.

The operation channel in v15 included strong teacher-provided arithmetic views. Future work should move toward self-generated internal operations.

The current glia system is mostly formula-based. Adaptive glia patches are a proposed next step, not yet proven.

More random seeds, larger task sets, and ablation tests are needed before treating any result as robust.

The project is inspired by biology but remains an engineering abstraction, not a detailed neuroscience simulation.

12. Conclusion

The v14-v20 project arc supports a cautious but meaningful conclusion: a code-based biological learner can learn while using rich experience, reflection, memory, task-specific pathways, and evolving spatial structure.

v15 showed that normal-path replay and operation-style thought tools can solve the tested toy tasks. v16 showed that 3D tissue can coexist with learning. v17-v20 showed that growth and pruning require more than fixed global rules.

The next bottleneck is glia stability: local regulators that learn the network itself. The next architecture should therefore use two hemispheres, multiple input-entry regions, guided developmental corridors, and adaptive glia patches that learn when to grow, prune, repair, stabilize, and reopen plasticity.
