Adaptive Biological AI Learner

A Portfolio Research Paper on Rich Experience, 3D Neural Tissue, Reflection, and Adaptive Glia

This project documents a code-based experimental architecture for a developmental, biological-style learner. The goal is to explore what a learner could look like if it were designed more like a growing biological tissue instead of a fixed flat neural network.

Executive Summary

The project moved away from flat binary input and toward rich experience objects that carry raw values, task context, relational information, operation-style views, memory traces, attention state, and teacher/reflection signals.

The strongest version, v15, solved the tested toy tasks by combining task-specific output heads, a reflection pass, normal-path replay, and an operation-style number-line workspace for addition.

Later 3D versions showed that spatial neural tissue can coexist with learning, but static global growth and pruning rules are too brittle. The current conclusion is that the base neuron and rich-experience learner are worth preserving, but the next bottleneck is glia stability.

Core Ideas

  • Rich experience objects instead of flat binary input
  • Task-specific output heads
  • Reflection followed by normal-path replay
  • Operation-style workspace for arithmetic
  • 3D neural tissue with local links and rare bridges
  • Slow forgetting and history-aware pruning
  • Future two-hemisphere structure
  • Adaptive glia patches for local tissue regulation

What Worked

Rich experience objects gave the learner more useful context than flat binary input. Task-specific heads reduced interference between different task types. Reflection helped, but normal-path replay was needed so the network learned to improve its first-pass answer instead of depending on teacher correction signals.

What Did Not Work

One shared scalar output was too crude. Growth-only tissue development caused overgrowth. Aggressive pruning destroyed too many spatial links. Stability alone did not guarantee useful pathways. These failures pointed toward the need for adaptive glia-like regulators.

Next Direction

The next proposed direction is a two-hemisphere model with separate input regions, guided developmental corridors, and adaptive glia patches. These glia patches would not produce task answers directly. Instead, they would monitor local tissue health and learn when to grow, prune, repair, stabilize, protect, or reopen plasticity.

Status

This is an early-stage research and portfolio project. It is not presented as finished artificial general intelligence. It is an engineering exploration of adaptive learning structures, biological-style regulation, and developmental neural organization.
